# Customise Your Life: Building Tiny Personal Tools with AI

Working materials for Arlen Brower's 45-minute Festival of AI talk and live
demo.

The workshop is about **software for one**: small, personally useful tools that
are easier to create with AI assistance, but still deserve clear boundaries,
simple tests, and an honest decision about whether they are worth building.

## Current materials

- [Workshop plan](docs/workshop-plan.md) — learning outcomes, 45-minute run
  sheet, demo strategy, facilitation notes, risks, and preparation checklist.
- [Dashboard hero demo](docs/dashboard-demo.md) — staged Firefox new-tab demo,
  non-programmer framing, build prompt, tests, and deployment ladder.
- [Tiny tool brief](materials/tiny-tool-brief.md)
  ([printable PDF](materials/tiny-tool-brief.pdf)) — a take-home worksheet and
  optional prompts for refining or prototyping an idea.
- [Talk slide deck](slides/customise-your-life-talk.pptx) — 14-slide
  conversation scaffold with the audience and customisation case up front, an
  optional BYOD path, live-demo handoffs, testing, boundaries, source notes,
  and presenter timings in speaker notes.
- [Workshop slide deck](slides/customise-your-life-workshop.pptx) — the earlier
  interactive version with individual, pair, and short sprint activities.
- [Prepared demo checkpoints](demo-backups/README.md) — an offline
  OpenDyslexic extension, a deliberately flawed dashboard, its focused fix,
  and the dashboard with one additional locally stored feature.
